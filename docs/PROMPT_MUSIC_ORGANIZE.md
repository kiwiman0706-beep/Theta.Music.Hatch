# NAS の music（音楽＋ミュージックビデオ）の整理を、ローカルの Claude Code に頼む文

自分の PC（Windows）で動く Claude Code に、下の「---」から下を貼る。

- **つないでおくドライブ：** NAS の共有フォルダ `music` と `Obsidian` を、ネットワークドライブとしてつないでおく（例 `M:`＝music、`O:`＝Obsidian）。
- **頼み方：** 1 回で全部やろうとせず、**フォルダ 1 つずつ**頼む（例：「まず ▶邦楽 の あ行 だけ」「次は _ミュージックビデオ の あ行」）。ただし**棚（`▶` で始まるフォルダ）づくりだけは最初に全部まとめて**やる（下の 2-1）。
- **ミュージックビデオの順番：** 曲の整理（1〜4）を先にする。ミュージックビデオ（5）は、アーティストの表記をそろえた後の方が結び付けやすい。

置き場所と名前の決まりの正本は、Theta.Hatch.Series の `spec/THETA_LIBRARY_SPEC.md` §4・§4.1。

---

NAS（Synology DS1825+）の共有フォルダ `music` を整理したいです。手伝ってください。

- 曲のタグとフォルダをそろえる
- ジャケットをそろえる
- Obsidian の Vault に音楽のノートを作る
- ミュージックビデオを決まった形に並べる

ミュージックビデオも、アプリ（Theta Music Hatch）で曲と結び付けて見られるようにする予定です。

## できあがりの形

```
M:\                                   ← 共有フォルダ music
├─ ▶邦楽\                            ← 棚（▶ で始まるフォルダ）。名前は自由
│  ├─ <アルバムアーティスト>\
│  │  └─ <アルバム> (<年>)\
│  │     ├─ 01 <曲名>.flac            ← ディスク 1 枚
│  │     ├─ 1-01 <曲名>.flac          ← 複数ディスク
│  │     └─ cover.jpg                 ← ジャケット
│  └─ Various Artists\<アルバム> (<年>)\…  ← オムニバス・サントラ
├─ ▶洋楽\ ・ ▶サントラ\ …
├─ ▶ミュージックビデオ\               ← ミュージックビデオの棚（名前はこれに決まり）
│  └─ <アーティスト>\
│     ├─ <アーティスト> - <曲名> (<年>).mp4
│     ├─ <アーティスト> - <曲名> (<年>).nfo
│     ├─ <アーティスト> - <曲名> (<年>)-thumb.jpg
│     └─ <アーティスト> - <曲名> (<年>) [Live 日本武道館 2019].mp4
├─ _プレイリスト\<名前>.m3u8
├─ _未整理\                           ← 決められなかった物（消さない）
├─ _整理の記録\<日時>.csv
└─ ダウンロード\ …                   ← ▶ の無いフォルダは読まない（そのままでよい）
```

アプリ（1.7.2 から）が曲として読むのは、`▶` で始まる棚の中だけです（Theta Movie Hatch と同じ決まり。棚が 1 つも無いうちは全部読みます）。

- `_` で始まるフォルダは、記録・置き場として読みません。
- `▶ミュージックビデオ` も、曲としては読みません（動画の再生は後の版）。

## やること（この順で。各段階で私に見せて OK をもらってから次へ）

### 1. 調べる（読むだけ）

次のことをまとめて見せてください。

- 件数・形式・今の並び方
- タグの欠け（アルバムアーティスト・年・トラック番号・ディスク番号）
- Shift_JIS などの文字化け
- 名前のゆれ（全角・半角、「The」の有無）
- ジャケットの有無（埋め込み・`cover.jpg`・`folder.jpg` など）
- 重複
- **曲のフォルダに紛れている動画**：`.mp4`・`.m4v`・`.mkv`・`.webm`・`.mov`・`.avi`・`.ts`。`.mp4` は音だけの物もあるので、ffprobe で映像があるかを確かめる

最後に、**棚の分け方の案**を出してください（例：`▶邦楽`・`▶洋楽`・`▶サントラ・アニメ`・`▶クラシック`・`▶子供の歌`）。分け方は私が決めます。

### 2-1. 棚をつくる（最初に 1 回、全部まとめて）

アプリは `▶` の棚が 1 つでもできると、**棚の外の曲を読まなくなります**。棚を少しずつ作ると、まだ入れていない曲がアプリから消えて見えます。そこで最初に、私が決めた分け方で棚を作ってください。

- 今の直下のフォルダを、中身はそのまま**フォルダごと**どれかの棚に移す案（CSV）を作る
- OK をもらったら、全部まとめて移す
- 細かい整理（2-2 以降）は、そのあと棚の中で少しずつやる

### 2-2. タグとフォルダの整理（§4）

スナップショットを撮るよう私に頼んでから、変更案 CSV を作ってください。列は「今の場所・新しい場所・直すタグ・理由・確かさ」です。

- **形：** `▶<棚>\<アルバムアーティスト>\<アルバム> (<年>)\01 <曲名>.flac`
  - 複数ディスクは `1-01`
  - オムニバスはアルバムアーティストを `Various Artists`（棚ごとに `▶<棚>\Various Artists\`）
  - 同じアーティストは 1 つの棚にまとめる（棚をまたいで分けない）
- **文字コード：** タグは UTF-8（MP3 は ID3v2.4）。Shift_JIS の古いタグは UTF-8 に直す。
- **アルバムアーティストを必ず入れる：** アプリはアルバムアーティストでアーティストとアルバムをまとめます。空だと、同じアルバムが歌手ごとに分かれます。プロデュース作・トリビュートのように別の歌手の曲が入るアルバムも、アルバムアーティストを 1 つに決めます。
- **アーティストの表記をそろえる：** 棚をまたいでも同じ表記にします。1 つにそろえた表記の一覧（`アーティスト表記.csv`：ゆれ → そろえた表記）を残してください。5. のミュージックビデオでも同じ表記を使います。

### 3. ジャケット（アプリのキャッシュにもなる）

- **`cover.jpg` を置く：** 各アルバムのフォルダに置いてください（正方形の JPEG、500px 以上、できれば 1000px 前後）。
  - 埋め込みのジャケットがあれば、取り出して `cover.jpg` にする（埋め込みは消さない・曲のファイルは変えない）
  - どこにも無いアルバムは一覧にして私に見せる（ネットから勝手に取ってこない）
- **アプリが探す順番：** WebDAV では、フォルダの画像を `cover` → `folder` → `front` → `album` の順に探します。DS audio では Audio Station のジャケットを使います（フォルダの `cover.jpg` も読みます）。
- **Vault 用のサムネイル：** 同じジャケットを 300px 前後に縮小した JPEG を、`O:\Theta Vault\Music\_files\<アルバムの id>.jpg` に置いてください（id は 4. の作り方）。大きな画像は Vault に入れない決まりです。

### 4. Vault のノート（アプリの書き出しと同じ形）

`lib/core/obsidian.dart` と同じファイル名・`id`・中身にしてください。同じ形で作れば、あとでアプリが書き出し直しても、ノートが二重にならず、手で書いたメモも残ります。

**置き場所**

- アルバム：`Music/Albums/<アーティスト> - <アルバム>.md`
- アーティスト：`Music/Artists/<アーティスト>.md`
- 名前に使えない文字 `\ / : * ? " < > | # ^ [ ]` は `_` にする。前後の空白は取り、120 文字まで

**アーティストとアルバムの名前**

- アーティストはアルバムアーティスト。空ならアーティスト、それも空なら `Unknown Artist`
- アルバム名が空なら `Unknown Album`

**id（アプリと同じ作り方。これで同じものだと見分けられる）**

- アルバム：`md5("music/album:" + 小文字のアーティスト + "\u0000" + 小文字のアルバム)`
- アーティスト：`md5("music/artist:" + 小文字のアーティスト)`
- 32 文字を `8-4-4-4-12` で区切った UUID の形にする

**アルバムの frontmatter**

- `theta: music/album@1`
- `id: …`
- `type: album`
- `artist: "[[Music/Artists/<アーティスト>|<アーティスト>]]"`
- `album: "…"`
- `year`・`genre`（あれば）
- `tracks: <曲数>`
- `nas_path: "nas://music/▶<棚>/<アルバムアーティスト>/<アルバム> (<年>)"`（共有フォルダからのパス）
- `tags: [music/album]`
- `updated: YYYY-MM-DD`
- `cover: "Music/_files/<id>.jpg"`（アプリはこの項目を消さずに残します）

**アーティストの frontmatter**

- `theta: music/artist@1`
- `id: …`
- `type: artist`
- `albums: <アルバム数>`
- `songs: <曲数>`
- `tags: [music/artist]`
- `updated: …`

**本文**

- `<!-- theta-music:begin (この区間は自動生成。外側に書いたメモは保持されます) -->` と `<!-- theta-music:end -->` の間に書く
- アルバムは `# アルバム名`・アーティストへのリンク・曲の表（`| # | Title | Artist |`）
- アーティストは `# 名前` と `## Albums` の一覧（`- [[Music/Albums/…|アルバム名]] (年)`）
- 区間の外は `## Notes` だけ置く

**すでにノートがあるとき**

- frontmatter の `favorite`・`favorite_songs`・`rating` など、私やアプリが付けた項目を消さない
- 自動生成区間の外に書いたメモも消さない
- 曲の表の `★`（お気に入りの印）も残す

**一覧（Bases）**

- `Music/アルバム.base` と `Music/アーティスト.base` は、**無いときだけ**作る（あれば触らない）
- カード表示で `cover` を出す見本を、別の名前（例 `Music/アルバム（ジャケット）.base`）で作ってもらえると嬉しいです

**Vault の登録**

- `O:\Theta Vault\.theta\vault.json` の `apps` に `music` が無ければ足す（ほかの項目は消さない）

### 5. ミュージックビデオ（§4.1）

今は仮置きの `M:\_ミュージックビデオ\` に、動画の共有フォルダ（8Tube）の `▶ミュージックビデオ`・`▶YouTube/Music` から移した物がまとめて入っています。1. で見つけた、曲のフォルダに紛れている動画も対象です。

**a. 調べる（読むだけ）**

動画ごとに、次の材料から「アーティスト・曲名・年・種類」を推測して一覧にしてください。

- ファイル名・フォルダ名
- 埋め込みのメタデータ（`ffprobe` の title・artist・date）
- yt-dlp の `.info.json`、同じ名前の `.jpg`・`.webp`

YouTube の題名によく付く飾りは、曲名から外して、種類の手がかりにだけ使ってください。

- 例：`(Official Music Video)`・`【MV】`・`[4K]`・`Full ver.`・`-YouTube`
- `ライブ`・`Live`・`LIVE` → 種類 live
- `Short ver.` → 補足 `[Short ver.]`

**b. 曲と結び付ける**

推測したアーティストを 2. の `アーティスト表記.csv` でそろえた表記に直し、曲名と一緒に、ライブラリの曲（タグ）と照らし合わせてください。

- 照らし合わせるときは、大文字・小文字、全角・半角、前後の空白、記号の違いを無視する
- 見つかったら、年・収録アルバムはその曲のタグから取る
- 見つからない物は「ライブラリに無い曲」として一覧に出す（動かしてよい。消さない）

**c. 変更案 CSV**

列は「今の場所・新しい場所・アーティスト・曲名・年・種類・結び付いた曲のパス・確かさ」です。

- 新しい場所：`▶ミュージックビデオ\<アーティスト>\<アーティスト> - <曲名> (<年>).<元の拡張子>`
  - `<アーティスト>` は歌っている人。音楽のアルバムアーティストのフォルダと同じ表記にする
  - 共演は主な 1 組のフォルダへ
  - 年が分からなければ `(<年>)` を付けない
- 同じ曲の別の映像（ライブ・別バージョン・ショート版）は、末尾の `[ ]` で区別する
  - 例：`[Live 日本武道館 2019]`・`[Short ver.]`・`[Dance ver.]`
- 中身が同じ重複（ハッシュが同じ）は、片方を `_未整理\重複\` に回す案にする（消さない）
- 確かさが低い物は `要確認` にする。アーティストが決められない物は `_ミュージックビデオ\` に残す

**d. 付属ファイルを作る（OK をもらった物だけ）**

`.nfo`（UTF-8、Kodi・Jellyfin の musicvideo 形式）。例：

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<musicvideo>
  <title>RIDE ON TIME</title>
  <artist>山下達郎</artist>
  <album>RIDE ON TIME</album>
  <year>1980</year>
  <premiered>1980-05-01</premiered>
  <genre>J-Pop</genre>
  <tag>mv</tag>
  <uniqueid type="youtube">XXXXXXXXXXX</uniqueid>
  <plot>元: https://www.youtube.com/watch?v=XXXXXXXXXXX</plot>
</musicvideo>
```

- **`<artist>`：** 共演なら 1 人ずつ並べる。
- **`<tag>`：** `mv`・`live`・`youtube`・`short` など。
- **YouTube 以外の物：** `uniqueid` と「元:」を付けない。
- **分からない項目：** 書かない（空のタグを作らない）。
- **すでに `.nfo` があるとき：** 私が書いた項目を消さず、足りない項目だけ足す。

`-thumb.jpg`（16:9、幅 640px 以上の JPEG）：

- yt-dlp のサムネイル（`.jpg`・`.webp`）があれば JPEG にして使う
- 無ければ、`ffmpeg` で動画の 20% あたりの 1 コマを切り出す
- 使い終わった `.webp`・`.info.json` は、動画と同じ名前にして隣に残す（消さない）

### 6. 終わったら

件数が合っているか（消えた物が無いか）を確かめ、`_整理の記録\<日時>.csv` と元に戻すスクリプトを残してください。
そのうえで、次が要るかを教えてください。

- Audio Station の再インデックス（DSM → Audio Station → 設定 → 再インデックス、または DSM のインデックスサービス）
- アプリ（Theta Music Hatch）の Library →「Rebuild Library」（WebDAV のとき。タグを直したので全部読み直す）
- Jellyfin を使っていれば、「ミュージックビデオ」のライブラリに `music\▶ミュージックビデオ` を足して再スキャン

## 守ってほしいこと（`PROMPT_NAS_ORGANIZE.md` と同じ。抜粋と追加）

- **消さない。** 重複・不明な物は `_未整理\` か一覧に回す。
- **ファイルの中身は変えない。** 曲も動画も、再エンコード・形式の変換をしない。
  - 直してよいのは曲のタグだけ。それも変更案で確認してから。
  - 動画のタグ（メタデータ）は書き換えず、情報は `.nfo` に書く。
- **1 回は数百件まで。** 大きな処理は、まず 10 件くらいで試して結果を見せてから。
- **道具：**
  - Python 3.12。タグは `mutagen`、画像は `Pillow`
  - 動画は `ffprobe`・`ffmpeg`（インストール済み）
  - 入っていない物は、入れ方を教えてから使う（`pip install mutagen`）
- **触らない物：**
  - Vault の `.obsidian\` や、ほかのアプリのフォルダ（`Meishi\`・`Memo\` など）
  - 動画の共有フォルダ（8Tube）。ミュージックビデオが残っていたら一覧に出すだけで、動かす前に私に聞く
- **ミュージックビデオの Vault のノートは、まだ作らない。** アプリが動画に対応する版で形を決めます。
