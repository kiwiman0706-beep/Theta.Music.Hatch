# 音楽の整理を、ローカルの Claude Code に頼む文

自分の PC（Windows か Mac）の Claude Code に、下のコードブロックの中を貼る。

- **つないでおくドライブ：** NAS の共有フォルダ `music` を、PC にネットワークドライブとしてつないでおく（Windows なら例えば `M:`）。Vault のノートも `music/_Theta Vault/` に置く。
- **頼み方：** 1 回で全部やろうとせず、**段階を 1 つ・棚を 1 つ・フォルダを 1 つ**ずつ頼む。ただし**段階 1（棚）だけは最初にまとめて**やる。
- **`＜…＞` の 3 か所：** 毎回書き換える（ドライブ・段階・対象）。
- **始める前に：** アプリを 1.8.0 以上にして、Library → Export to Obsidian を 1 回。

```text
NAS（Synology DS1825+）の音楽を整理したいです。手伝ってください。

## 決まり

GitHub の kiwiman0706-beep/Theta.Music.Hatch（公開）の docs/naming-convention.md に、並べ方・名前・タグ・ジャケット・Vault のノート・ミュージックビデオ・整理の約束・整理の記録の形がすべて書いてあります。最初に全部読んでください。
https://github.com/kiwiman0706-beep/Theta.Music.Hatch/blob/main/docs/naming-convention.md
（読めなければ私に言ってください）

- 共有フォルダは DSM のパスで /music、PC からは ＜例：M:\＞ で見えています（Vault のノートは /music/_Theta Vault/Music/）
- 今回の段階：＜例：規則 §11 の 1「棚」＞ だけ。ほかの段階のことはしないでください
- 今回の対象：＜例：M:\ の直下のフォルダ全部 → ▶邦楽・▶洋楽・▶サントラ へ＞

## 進め方

1. 調べる：対象を読むだけで調べ、件数・形式・今の並び・問題をまとめて見せてください。まだ何も動かさないでください
   - 問題の例：タグの欠け（特にアルバムアーティスト）、文字化け（Shift_JIS）、表記のゆれ、ジャケットの有無、重複、NFD の名前、使えない文字、曲のフォルダに紛れた動画
   - タグは mutagen、動画の長さ・映像の有無は ffprobe で（無ければ入れ方を教えてから。Windows は winget か pip、Mac は Homebrew か pip）
   - 段階 1 のときは、棚の分け方の案（どのフォルダをどの棚へ）も出してください。分け方は私が決めます
2. スナップショット：DSM で /music のスナップショットを撮るよう、私に頼んでください（私が撮ります）
3. 変更案：規則の形に合わせた変更案を CSV（元の場所・新しい場所・直すタグ・理由・確かさ）で作り、要点を表で見せてください。確かさの低い物は「要確認」にして私に聞いてください
   - 場所は DSM のパス（/music/…）で書いてください（整理の記録にそのまま使うため）
4. 実行：私が OK した物だけ、1 回数百件まで動かしてください。まず 10 件くらいで試して結果を見せてから
   - 動かしたら、規則 §12 の形で /music/_整理の記録/<日時>.csv を書いてください
   - 元に戻すスクリプトも一緒に作ってください（元に戻したときも、逆向きの記録を新しい日時で残す）
   - タグを直したときは、元の値を <日時>-tags.csv に残してください
5. 確かめる：件数が合っているか（消えた物が無いか）を確かめて教えてください。最後に、次のうち要る物を私に言ってください
   - Audio Station の再インデックス
   - Theta Music Hatch の Library →「Rebuild Library」（DS audio なら「Scan」）
   - Jellyfin の再スキャン

## 守ってほしいこと

- 消さない。重複・不明な物は /music/_未整理/ か一覧に回す
- 中身を変えない（曲も動画も、再エンコード・形式の変換をしない）。直してよいのは曲のタグだけで、それも変更案で私が OK した物だけ。動画のタグは書き換えない（情報は .nfo に）
- 曲・動画と同じ名前の付属ファイル（.lrc・.cue・.nfo・-thumb.jpg・.info.json など）は一緒に動かす。_プレイリスト の .m3u8 があれば中のパスも直す
- ▶ の付いていないフォルダは、対象に言われた物以外は触らない。@eaDir・#recycle は触らない
- Vault（/music/_Theta Vault/）の .obsidian/ や、/Obsidian の Theta Vault（Meishi/・Memo/ など）は触らない
- 道具は Python 3.12 で（入っていない物は入れ方を教えてから）
```
