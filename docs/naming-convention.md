# 音楽ライブラリの整理ルール v1.2（Theta Music Hatch）

> このファイル 1 つに、音楽とミュージックビデオの並べ方・名前・タグ・付属ファイル・整理の手順と約束をまとめる（2026-11-19）。
> ローカルの Claude に整理を頼むときも、これだけを読ませればよい（頼む文：[`PROMPT_LOCAL_ORGANIZE.md`](PROMPT_LOCAL_ORGANIZE.md)）。
> 形は Theta Movie Hatch の `docs/naming-convention.md`（8Tube）とそろえてある。Theta.Hatch.Series の `spec/THETA_LIBRARY_SPEC.md` §4 から参照されるので、**このファイルの場所は変えない**。

目的：**Theta Music Hatch が無くなっても、Audio Station・Jellyfin・Plex・Kodi・foobar2000・MusicBee でそのまま読める**こと。

## 履歴

- v1.0（2026-11-19）：最初の版。共有フォルダ `/music`・棚の目印 `▶`・ミュージックビデオの形・整理の記録の形（§12）を決めた
- v1.1（2026-11-20）：Vault のノートの置き場所を、ライブラリと同じ共有フォルダの **`/music/_Theta Vault/Music/`** にした（§7。Theta.Hatch.Series の `THETA_VAULT_SPEC.md` §4）
- v1.2（2026-11-21）：アルバムアーティストのそろえ方を利用者の指示で決めた（§3）。オムニバスは `Various Artists`、あるアーティストのアルバムで一部の曲が連名でも主なアーティスト。アーティスト一覧がややこしくならないように

## 0. 基本

1. **正本はタグ**。フォルダ名・ファイル名はタグから作る（Audio Station・Jellyfin・アプリはタグを読む）
2. **フォルダ 1 つ＝アルバム 1 枚**。`<アルバムアーティスト>/<アルバム> (<年>)/`
3. 曲は **`01 <曲名>`**（トラック番号は半角 2 けた）。複数ディスクは **`1-01 <曲名>`**
4. ジャケットはアルバムのフォルダの **`cover.jpg`**
5. **曲・動画の中身は変えない**（再エンコード・形式の変換をしない）。直してよいのは**曲のタグだけ**
6. 補足は末尾の `[ ]`（ミュージックビデオの別の映像など）

## 1. 共有フォルダと棚

- 音楽の共有フォルダは **`/music`**（DSM の File Station から見たパス。PC からはネットワークドライブ、例 `M:`）
- その直下の、名前が **`▶` で始まるフォルダ＝棚**。Theta Music Hatch（1.7.2 から）は、棚が 1 つでもあれば**棚の中だけ**を読む。棚が 1 つも無いうちは全部読む
- **▶ の無いフォルダは読まない**。ダウンロードの置き場・作業用はそのままでよい
- `_` で始まるフォルダ（`_整理の記録`・`_未整理`・`_プレイリスト`・`_Theta Vault`）は記録・置き場で、曲として読まない
- **棚は最初にまとめて作る**（§11 の段階 1）。少しずつ作ると、まだ入れていない曲がアプリから消えて見える

| 棚のフォルダ | 中身 |
|---|---|
| `▶邦楽` | 日本のポップス・ロックなど（例） |
| `▶洋楽` | 海外のポップス・ロックなど（例） |
| `▶サントラ` | 映画・ドラマ・アニメ・ゲームの音楽（例） |
| `▶<独自の名前>` | 例：`▶クラシック`・`▶ジャズ`・`▶子供の歌`・`▶落語` |
| **`▶ミュージックビデオ`** | ミュージックビデオ（§8）。**名前はこれに決まり**。曲としては読まない |

- 棚の分け方は利用者が決める。**同じアーティストは 1 つの棚**にまとめる（棚をまたいで分けない）

```
/music/
├─ ▶邦楽/
│  ├─ 山下達郎/
│  │  └─ RIDE ON TIME (1980)/
│  │     ├─ 01 RIDE ON TIME.flac
│  │     └─ cover.jpg
│  └─ Various Artists/
├─ ▶洋楽/
├─ ▶ミュージックビデオ/
├─ _プレイリスト/
├─ _整理の記録/          ← 整理のたびの記録（§12）。消さない
├─ _未整理/              ← 決められなかった物
├─ _Theta Vault/          ← アルバム・アーティストのノート（§7）。Obsidian で保管庫として開く
└─ _ミュージックビデオ/   ← 8Tube から移した動画の仮置き（§8 の形にして ▶ミュージックビデオ へ）
```

## 2. アルバム

```
▶邦楽/
└─ 山下達郎/                              ← アルバムアーティスト
   ├─ RIDE ON TIME (1980)/                ← アルバム (最初の発売年)
   │  ├─ 01 RIDE ON TIME.flac
   │  ├─ 02 SPARKLE.flac
   │  └─ cover.jpg
   └─ OPUS ALL TIME BEST 1975-2012 (2012)/
      ├─ 1-01 SPARKLE.flac                ← ディスク 1 の 1 曲目
      ├─ 4-15 さよなら夏の日.flac
      └─ cover.jpg
```

- フォルダ名は `<アルバム> (<年>)`。年は最初の発売年（リマスター・再発でも元の年。再発を分けたいときは末尾 `[2020 Remaster]`）
- **ディスクのフォルダ（`Disc 1/`）は作らない**。番号で `1-01` とする（アプリは `Disc 1/` も読めるが、そろえる）
- **アルバムに入っていない曲（シングル・配信の 1 曲）**：`<アーティスト>/<曲名> (<年>) [Single]/01 <曲名>.flac` のように、シングル 1 枚を 1 つのアルバムとして扱う
- ボーナストラック・隠しトラックもトラック番号どおりに

## 3. アーティスト

- **アルバムアーティスト**でフォルダを分ける。曲ごとの歌手（フィーチャリング・デュエット）は曲のアーティストのタグに書く
- **アーティスト一覧がややこしくならないように、アルバムアーティストは次のどちらかにそろえる**（2026-11-21 利用者の指示）
  - **オムニバス**（いろいろな歌手のアルバム：コンピレーション・サントラ・トリビュート・カバー集・寄せ集め）→ **`Various Artists`**。表記は `Various Artists` に統一（`V.A.`・`VARIOUS ARTISTS`・`オムニバス`・`ヴァリアス・アーティスト` などは直す）
  - **あるアーティストのアルバム**で、一部の曲が別の参加アーティストと連名（`KAN + キマグレン + 一青窈`・`feat.` など）→ アルバムの**主なアーティスト**。連名は曲のアーティストのタグにだけ書く
  - 見分け方の目安：アルバムのフォルダの持ち主（アーティストのフォルダ）が曲の 3 割未満にしか出てこず、歌手が 3 人以上ならオムニバス
- オムニバス・サントラ・トリビュート（いろいろな歌手）：アルバムアーティストは **`Various Artists`**。フォルダは `▶<棚>/Various Artists/<アルバム> (<年>)/`
  - ただし「〇〇プロデュース」「〇〇トリビュート」で 1 人に結び付けたいときは、そのアーティストをアルバムアーティストにしてよい（どちらかに決めて記録に書く）
- **表記をそろえる**：全角・半角、`The` の有無、大文字・小文字、旧名・別名義。そろえた表記の一覧を `/music/_整理の記録/アーティスト表記.csv`（`ゆれ,そろえた表記`）に残し、棚をまたいでも同じ表記を使う
- 別名義（例 `坂本龍一` と `YMO`）は別のアーティスト。合わせない
- 読み：`ARTISTSORT`・`ALBUMARTISTSORT`（例 `やましたたつろう`）。英語名の `The` は `ARTISTSORT` で後ろへ（`Beatles, The`）

## 4. タグ

| 項目 | 必ず | 例 | MP3（ID3v2.4） | FLAC（Vorbis） | M4A（iTunes） |
|---|---|---|---|---|---|
| 曲名 | ○ | `RIDE ON TIME` | TIT2 | TITLE | ©nam |
| アーティスト | ○ | `山下達郎` | TPE1 | ARTIST | ©ART |
| アルバムアーティスト | **○** | `山下達郎` | TPE2 | ALBUMARTIST | aART |
| アルバム | ○ | `RIDE ON TIME` | TALB | ALBUM | ©alb |
| 年 | ○ | `1980` | TDRC | DATE | ©day |
| トラック番号 | ○ | `1`（/総数は任意） | TRCK | TRACKNUMBER | trkn |
| ディスク番号 | 複数枚なら | `1`（/総数） | TPOS | DISCNUMBER | disk |
| ジャンル | 任意 | `J-Pop` | TCON | GENRE | ©gen |
| 読み | 任意 | `やましたたつろう` | TSOP・TSO2・TSOA | ARTISTSORT など | soar など |
| ジャケット | 任意 | 埋め込み（`cover.jpg` があれば無くてよい） | APIC | METADATA_BLOCK_PICTURE | covr |

- **文字コードは UTF-8**。MP3 は **ID3v2.4**（v2.3 の UTF-16 も可）。古い ID3v1・Shift_JIS のタグは UTF-8 に直す（文字化けの直し方は一覧で確認してから）
- **アルバムアーティストは必ず入れる**。空だと、同じアルバムが歌手ごとに分かれる（アプリ・Audio Station とも）
- 複数のアーティストは、曲のアーティストに `山下達郎 & 竹内まりや` のように 1 つの文字列で（区切りは ` & `・` feat. `）
- コメント・歌詞・作曲者などの既存のタグは**消さない**
- WAV はタグが弱いので、タグを付けたいときも**変換しない**（一覧に出すだけ）

## 5. ファイル名

- `<トラック番号 2 けた> <曲名>.<拡張子>`（複数ディスクは `<ディスク>-<トラック 2 けた> <曲名>`）
- 曲名はタグのまま（§9 の文字の決まりだけ当てる）。アーティスト名はファイル名に入れない（フォルダにあるため）
  - オムニバスだけは `01 <アーティスト> - <曲名>.flac` でもよい
- 拡張子は小文字（`.FLAC` → `.flac`）

## 6. ジャケット

- アルバムのフォルダに **`cover.jpg`**（正方形の JPEG、500px 以上、できれば 1000px 前後）
  - 埋め込みのジャケットがあれば、取り出して `cover.jpg` にする（埋め込みは消さない）
  - `folder.jpg`・`front.jpg` などがあれば、それを `cover.jpg` に（元のファイルは残す）
  - どこにも無いアルバムは一覧にする（ネットから勝手に取ってこない）
- アプリは、WebDAV ではフォルダの `cover` → `folder` → `front` → `album` の順に探す。DS audio では Audio Station のジャケット（フォルダの `cover.jpg` も読む）
- **Vault 用のサムネイル**：同じジャケットを 300px 前後に縮小した JPEG を `/music/_Theta Vault/Music/_files/<アルバムの id>.jpg` に（§7）

## 7. Vault のノート

アプリの Library → Export to Obsidian と**同じ形**で作る（`lib/core/obsidian.dart`）。同じ形なら、あとでアプリが書き出し直しても二重にならず、手で書いたメモも残る。

- 置き場所：**`/music/_Theta Vault/Music/`**（ライブラリと同じ共有フォルダ。2026-11-20 決定。スナップショット・バックアップ・移動で、曲とノートが離れないため）
  - `_Theta Vault/` は中の形が Theta Vault と同じで、Obsidian では**ほかの Vault（`/Obsidian/Theta Vault/`、名刺・メモなど）とは別の保管庫**として開く
  - 先頭が `_` なので棚としては読まれない（§1）
  - アプリの Export to Obsidian の既定の書き出し先は、今は `Obsidian/Theta Vault/Music`（後の版で変える。それまでは設定で `music/_Theta Vault/Music` を選ぶ）
  - アルバム：`Albums/<アーティスト> - <アルバム>.md`
  - アーティスト：`Artists/<アーティスト>.md`
  - 名前に使えない文字 `\ / : * ? " < > | # ^ [ ]` は `_`。前後の空白は取り、120 文字まで
  - アーティストはアルバムアーティスト（空ならアーティスト、それも空なら `Unknown Artist`）。アルバムが空なら `Unknown Album`
- id（アプリと同じ作り方）：
  - アルバム：`md5("music/album:" + 小文字のアーティスト + "\u0000" + 小文字のアルバム)`
  - アーティスト：`md5("music/artist:" + 小文字のアーティスト)`
  - 32 文字を `8-4-4-4-12` に区切った UUID の形
- アルバムの frontmatter：`theta: music/album@1`・`id`・`type: album`・`artist: "[[Music/Artists/<アーティスト>|<アーティスト>]]"`・`album`・`year`・`genre`・`tracks`・`nas_path: "nas://music/▶<棚>/<アルバムアーティスト>/<アルバム> (<年>)"`・`tags: [music/album]`・`updated: YYYY-MM-DD`・`cover: "Music/_files/<id>.jpg"`
- アーティストの frontmatter：`theta: music/artist@1`・`id`・`type: artist`・`albums`・`songs`・`tags: [music/artist]`・`updated`
- 本文：`<!-- theta-music:begin (この区間は自動生成。外側に書いたメモは保持されます) -->` と `<!-- theta-music:end -->` の間に、アルバムは `# アルバム名`・アーティストへのリンク・曲の表（`| # | Title | Artist |`）、アーティストは `# 名前` と `## Albums`（`- [[Music/Albums/…|アルバム名]] (年)`）。区間の外は `## Notes` だけ
- **すでにノートがあるとき**：`favorite`・`favorite_songs`・`rating` など利用者・アプリが付けた項目、区間の外のメモ、曲の表の `★` を消さない
- 一覧：`Music/アルバム.base`・`Music/アーティスト.base` は**無いときだけ**作る。ジャケットのカード表示の見本は別の名前（`Music/アルバム（ジャケット）.base`）で
- `/music/_Theta Vault/.theta/vault.json` の `apps` に `music` が無ければ足す（ほかの項目は消さない）
- Vault の `.obsidian/` や、ほかのアプリのフォルダは触らない

## 8. ミュージックビデオ

PV・MV、ライブ映像の 1 曲分、YouTube の MV。**コンサート 1 本まるごと**は 8Tube の `▶ライブ`（Movie Hatch）。

```
▶ミュージックビデオ/
└─ 山下達郎/                                        ← 歌っている人
   ├─ 山下達郎 - RIDE ON TIME (1980).mp4
   ├─ 山下達郎 - RIDE ON TIME (1980).nfo
   ├─ 山下達郎 - RIDE ON TIME (1980)-thumb.jpg
   ├─ 山下達郎 - RIDE ON TIME (1980) [Live 日本武道館 2019].mp4
   └─ 山下達郎 - クリスマス・イブ (1983) [Short ver.].mp4
```

- フォルダは**歌っている人**。表記は、曲のアルバムアーティストのフォルダと**同じ**（§3 の一覧）。アプリはこの名前と曲名でライブラリの曲と結び付ける（後の版）
- 共演は主な 1 組のフォルダに置き、全員を `.nfo` の `<artist>` に並べる
- ファイル名：`<アーティスト> - <曲名> (<年>).<元の拡張子>`。年は公開・発売の年、分からなければ付けない
- 同じ曲の別の映像は末尾の `[ ]`：`[Live 日本武道館 2019]`・`[Short ver.]`・`[Dance ver.]`・`[Lyric Video]`
- 曲名は飾りを外す：`(Official Music Video)`・`【MV】`・`[4K]`・`Full ver.`・`- YouTube` など。`Live`・`ライブ` は `[Live …]` に
- **`.nfo`**（UTF-8、Kodi・Jellyfin の musicvideo 形式）。分からない項目は書かない

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<musicvideo>
  <title>RIDE ON TIME</title>
  <artist>山下達郎</artist>
  <album>RIDE ON TIME</album>
  <year>1980</year>
  <premiered>1980-05-01</premiered>
  <genre>J-Pop</genre>
  <tag>mv</tag>
  <uniqueid type="youtube">XXXXXXXXXXX</uniqueid>
  <plot>元: https://www.youtube.com/watch?v=XXXXXXXXXXX</plot>
</musicvideo>
```

  - `<tag>`：`mv`・`live`・`youtube`・`short`・`lyric` など
  - `<album>`・`<year>` は、結び付いた曲のタグから取る
  - すでに `.nfo` があれば、利用者が書いた項目を消さず、足りない項目だけ足す
- **`-thumb.jpg`**：16:9、幅 640px 以上の JPEG。yt-dlp のサムネイル（`.jpg`・`.webp`）があれば JPEG にして使う。無ければ動画の 20% あたりの 1 コマ（`ffmpeg`）
- yt-dlp の `.info.json`・`.webp` などは、動画と同じ名前にして隣に残す（消さない）
- **動画の中身もタグも変えない**（情報は `.nfo` に）
- Vault のノートはまだ作らない（アプリが動画に対応する版で決める）

## 9. 文字

### 9-1. 使えない文字は全角に

| 半角 | 全角 |
|---|---|
| `:` | `：` |
| `?` | `？` |
| `/` | `／` |
| `\` | `＼` |
| `*` | `＊` |
| `"` | `”` |
| `<` `>` | `＜` `＞` |
| `|` | `｜` |

- 名前の最後にスペースや `.` を置かない。先頭に `.` を置かない
- 先頭の `▶` は棚だけ、先頭の `_` は記録・置き場だけに使う（アーティスト・アルバムの名前の先頭なら全角 `＿` に）

### 9-2. そろえ方

- Unicode は **NFC**（Mac で作った名前の濁点が分かれていたら直す）
- 英数字は半角、カタカナは全角（半角カナは全角に）
- 前後・連続の空白は 1 つに
- タグの中身（曲名・アルバム名）は §9-1 の置き換えをしない（ファイル名・フォルダ名だけ）

### 9-3. 長さ

- ファイル名・フォルダ名は 120 文字以内。長いときは曲名・アルバム名を `…` で切る（タグはそのまま）

## 10. 曲以外のファイル

- `_プレイリスト/<名前>.m3u8`：UTF-8、パスは `/music` からの相対（`../▶邦楽/…`）。曲を動かしたら中のパスも直す
- `.cue`・`.log`（CD の取り込み記録）・ブックレットの画像（`scans/`）：アルバムのフォルダにそのまま置く
- 歌詞の `.lrc`：曲と同じ名前で隣に
- Synology の `@eaDir`・`#recycle` は触らない

## 11. 整理の進め方（段階）

1. **棚**：今の直下のフォルダを、中身はそのまま**フォルダごと**どれかの棚へ。**最初に全部まとめて**やる
2. **タグ**：§4 のとおりに直す（文字化け・アルバムアーティスト・年・番号・表記のゆれ）。名前と場所はまだ変えない
3. **名前と場所**：直したタグから §2・§3・§5 の形に並べ替える
4. **ジャケット**：§6
5. **Vault のノート**：§7（アプリの Export to Obsidian で足りるなら、それでもよい）
6. **ミュージックビデオ**：`_ミュージックビデオ/` と、曲のフォルダに紛れた動画を §8 の形にして `▶ミュージックビデオ/` へ

**整理を始める前に必ず：**
- Theta Music Hatch を **1.8.0 以上**に（整理の記録を読んで、曲のお気に入りを新しい場所に付け替える）
- アプリで Library → **Export to Obsidian** を 1 回（お気に入りが Vault のノートにも残る。万一のときは Restore Favorites で戻せる）
- アルバム・アーティストのお気に入りは**名前**で覚えているので、タグでアルバム名・アルバムアーティストの表記を直すと外れる。直した後に付け直す（曲のお気に入りは記録で付け替わる）
- DS audio の★（Audio Station の評価）は、曲を動かすと消えるかもしれない（未確認）。気になるなら、★の付いた曲の一覧を Audio Station で先に書き出しておく

## 12. 整理の約束と記録

1. 始める前に、`/music`（Vault の `_Theta Vault/` もこの中）の **Btrfs スナップショット**を撮る（DSM の Snapshot Replication。撮るのは利用者）
2. まず **変更案の CSV**（元の場所・新しい場所・直すタグ・理由・確かさ）を作り、要点を見せる。確かさの低い物は「要確認」で、利用者に聞く
3. 利用者が OK した物だけ動かす。**1 回は数百件まで**、棚ごと・フォルダごとに。大きな処理は、まず 10 件くらいで試す
4. 動かしたらすぐ **整理の記録**を書く（下の形）。**1 つのコマンドで元に戻せる**スクリプトも作る。タグを直したときは、元のタグを `_整理の記録/<日時>-tags.csv`（`場所,項目,元の値,新しい値`）に残す
5. **消さない**。重複・不明な物は `_未整理/` か一覧に回す（中身が同じ重複は、片方を `_未整理/重複/` へ）
6. **中身を変えない**（再エンコード・変換をしない）。直すのは曲のタグだけ
7. 終わったら件数を確かめる（消えた物が無いか）。Audio Station の再インデックス、アプリの Rebuild Library（DS audio は Scan）、Jellyfin の再スキャン

### 整理の記録（Theta Music Hatch が読む）

Theta Movie Hatch と同じ形。

- 置き場所：**`/music/_整理の記録/<日時>.csv`**（例 `20261119-213000.csv`。日時の順に読む）
- 文字コード UTF-8。1 行目は見出し `元の場所,新しい場所,理由`
- **1 列目・2 列目は DSM のパス**（`/music/…` で始まる。PC のドライブ文字 `M:\…` ではない）。区切りは `/`
- ファイルを動かしたら 1 行。**フォルダごと動かした・名前を変えた**ときはフォルダの 1 行でよい（中の曲もまとめて付け替える）
- カンマを含む名前は `"…"` で囲む（中の `"` は `""`）
- **元に戻したとき**も、逆向き（新しい場所 → 元の場所）の記録を新しい日時の CSV で残す
- 記録は消さない・書き換えない（アプリは、読み込んだ記録を覚えて二度当てない）
- タグだけの記録（`-tags.csv`）・アーティスト表記の一覧は、名前が `.csv` で終わっても見出しが違うのでアプリは読み飛ばす

```csv
元の場所,新しい場所,理由
/music/邦楽/山下達郎,/music/▶邦楽/山下達郎,棚へフォルダごと
/music/▶邦楽/山下達郎/RIDE ON TIME/01 ride on time.mp3,/music/▶邦楽/山下達郎/RIDE ON TIME (1980)/01 RIDE ON TIME.mp3,タグから
/music/_ミュージックビデオ/RIDE ON TIME (Official).mp4,/music/▶ミュージックビデオ/山下達郎/山下達郎 - RIDE ON TIME (1980).mp4,ファイル名と曲のタグから
```
