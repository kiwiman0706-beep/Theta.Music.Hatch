Theta Hatch シリーズとしての最初の版です。

- アプリ ID を `app.thetahatch.music` に、署名をシリーズ共通の鍵に変えました。**前のお試し版（Theta Music）には上書きできません。アンインストールしてから入れてください**（ライブラリは入れ直したあとに更新すれば戻ります。お気に入りは、前に Obsidian へ書き出していれば「お気に入りを戻す」で戻せます）
- 更新は Theta Home Hatch（または KidsHome）に頼みます（設定の「更新する」。ハブが無ければこのページを開きます）
- Theta Home Hatch の設定（スキン、NAS の接続先・パスワード・2 段階認証のデバイストークン）を受け取れます
- Theta Home の棚に、お気に入りと最近再生したアルバムが並び、押すと再生します
- スキンをシリーズの 11 種に（TERMINAL・BRAUN・SOFT・WINDOW・LCD を追加）。iPod の見た目も選べます
- Obsidian の書き出しをシリーズの Theta Vault（NAS の `Obsidian/Theta Vault/Music/`）に。一覧は Obsidian Bases（`.base`）、ノートに `id`
- パスワードとデバイストークンを端末内で暗号化して保存

実機で確かめていないことは `TESTING.md` にあります。
