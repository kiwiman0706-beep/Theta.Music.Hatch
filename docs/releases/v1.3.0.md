- **クリックホイールを iPod に忠実に**（Theta スキン）：ホイールが「リスト」と「再生中」のどちらを操作しているか（フォーカス）を持つようにしました
  - 曲を選ぶと、フォーカスが再生中のパネルに移ります（iPod が Now Playing に移るのと同じ）
  - 再生中：回すと音量、中央ボタンでシーク（もう一度押すか、しばらく触らなければ戻る）、中央の長押しでお気に入り、MENU でリストへ
  - リスト：回すと選ぶ、中央で決定、MENU で戻る。いちばん上の画面で MENU を押すと再生中へ
  - 指で触った側にもフォーカスが移ります。再生中のパネルの長押しでキュー
- 再生中のパネル：ジャケットをパネルいっぱいの背景にし、ビジュアライザーは曲名と進み具合の間にアクセントとして
- リストにサムネイル（アルバム・アーティスト・曲・キュー。iPod スキンはアルバム・アーティストの一覧だけ）
- 直したこと
  - アーティストの「すべての曲」に、アルバムアーティストが同じアルバムに入っている別の歌手の曲が混ざっていた（曲のアーティストで絞るように）
  - 続けて曲を選んだとき、先に選んだ曲順があとから入って、選んでいない曲が流れることがあった
