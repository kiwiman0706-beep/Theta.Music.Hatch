- Theta スキンの画面を作り直しました。iPod と同じ操作（リストを選ぶ・クリックホイール・MENU で戻る）を、シリーズのスキンの見た目で使えます
  - 横向き（タブレット）：左にタブ付きのリスト、右に再生中の曲とクリックホイール
  - 縦向き（スマホ）：上にリスト、下に再生中の曲とクリックホイール
  - 左のタブ：アーティスト・アルバム・曲・ジャンル・フォルダ・お気に入り・検索・ライブラリ・設定
  - 再生中の曲を押すと、キュー（前の曲も含めて全部）を開きます
  - テーマ（11 種）は 設定 → Theme
- 直したこと
  - 再生中の曲とは違う曲名が出ることがあった（曲順を入れ替えている途中の通知で、ずれた曲を指していた）
  - アルバムの途中の曲から再生すると、キューにそれより前の曲が出なかった
- iPod スキンでも、リストの中の再生中の曲に印が付きます
